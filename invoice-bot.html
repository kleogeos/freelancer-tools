Send one invoice from Telegram — no kit, no terminal

Message a bot with plain text, pay 100 Stars (~$1.3), get a polished HTML invoice back in seconds.

100 ⭐ (~$1.3) via Telegram

Message @freelancerkitbot →

No signup, no account, no KYC. Opens Telegram — pay from your Stars balance.

How it works

  1. Open a chat with @freelancerkitbot and send a message starting with /invoice, one field per line:
/invoice
from: Your Name
to: Client Name
invoice_number: INV-001
date: 2026-10-20
due_date: 2026-11-20
item: Website redesign | 10 | 50
item: Logo design | 1 | 200
  1. The bot replies with a priced preview (subtotal, tax if you set one, total) and a payment link.
  2. Pay 100 Stars. You get a ready invoice.html file back as a document — open it in any browser, print it, or attach it to an email.

item lines use description | quantity | rate, one per line — at least one required. from/to are required; invoice_number, date, due_date, tax_rate, notes are optional.

Why not just use the free tool?

The free invoice generator on this site does the same rendering and costs nothing — but it expects you to edit a JSON file or fill a form in a browser tab you have to keep open. This bot is for when you're already in Telegram talking to a client and just want a file sent back to that same chat, no new tab, no file to find afterward. It's a convenience, not a better invoice — the output is byte-for-byte the same template.

Need more than one invoice?

Sending several invoices a month? Message the bot /subscribe for unlimited invoices at 250 Stars/month (~$3.25) instead of 100 Stars each — break-even at 3 invoices. /status checks your period, /cancel stops renewal (you keep access until the period you paid for ends). If you also send proposals, contracts, and late-payment emails, the Freelancer Starter Kit ($15, one-time) bundles those as plain Markdown files you keep and reuse for every client, not a per-invoice bot.
